# DevSprig

A cross-platform desktop application that helps game developers plan, organize, design, and manage their projects.

## Status

DevSprig is currently in early development.

## Features

- Import Google Form responses from playtesters.
- DevSprig summarizes information.
- Tells developer possibilities of what to do next.
- Connects to ChatGPT (optional) to help with written responses.
